# Gerador de Storys · Sr.iPhone

Ferramenta para montar os stories da Sr.iPhone (1080×1920) a partir de modelo, cor, armazenamento, condição, quantidade, valor e foto do aparelho.

Tudo fica num único arquivo, `index.html`, sem instalação: as imagens (sticker, foguinho, logo) vão embutidas e as fontes vêm do Google Fonts.

## Usar no celular
1. Abra o endereço do site no **Safari** do iPhone.
2. Toque em Compartilhar › **Adicionar à Tela de Início** para abrir como um app.
3. **Baixar** abre a tela de compartilhar do iPhone: toque em **Salvar imagem** para mandar para Fotos. O ícone de compartilhar leva ao Instagram › Story.

## Publicar com GitHub Pages
Settings › Pages › Source: *Deploy from a branch* › Branch `main` / pasta `/ (root)`.
